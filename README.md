# Simple Calculator

## Objective
To develop a simple calculator using Python that performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero error handling

## Requirements
- Python 3
- VS Code or any Python editor

## How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open the terminal.
4. Run the command:

   python calculator.py

## Sample Output
Addition Result: 40

## Testing
Test all four arithmetic operations, invalid inputs, and division by zero.
