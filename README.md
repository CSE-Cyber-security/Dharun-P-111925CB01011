# Factorial Program

## Problem Statement
Write a Python program to find the factorial of a given number.

## Algorithm
1. Start.
2. Read the number n.
3. Set fact = 1.
4. Multiply fact by each number from 1 to n.
5. Display the factorial.
6. Stop.
