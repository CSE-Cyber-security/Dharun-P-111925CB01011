# Daily Expense Tracker

## Objective
To develop a simple Daily Expense Tracker using Python that logs expenses across categories and calculates total expenditure.

## Features
- Add daily expenses by category
- View categorized expenses list
- Automatic total calculation
- Input validation (rejects invalid text and negative amounts)
- Menu-driven interface

## Requirements
- Python 3
- VS Code or any Python editor

## How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open the terminal.
4. Run the command:
   python expense_tracker.py

## Sample Output
Added Rs 150.00 under 'Food'.
Total: Rs 210.00

## Testing
Test adding multiple items, viewing empty and filled lists, and testing non-numeric or negative values.
